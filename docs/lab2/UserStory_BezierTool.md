# User Story: Bezier Curve Drawing Tool

**Feature:** Bezier Tool (Scribble / Polygon / Path Drawing)

**User Story:**

> As a graphic designer,
> I want to draw freeform bezier curves and polygons by clicking and dragging on the canvas,
> so that I can create smooth, adjustable vector paths for my illustrations and diagrams.

## Acceptance Criteria

1. The user can select the Bezier tool from the tool palette.
2. The user can click on the drawing canvas to place nodes that define a bezier path.
3. The user can drag the mouse to create a freehand scribble that is automatically fitted to a smooth bezier curve.
4. The user can close a path by clicking near its starting point.
5. The user can double-click or switch tools to finish drawing the path.
6. After creation, the user can adjust individual node positions and control point handles to refine the curve shape.
7. The user can delete nodes from an existing bezier path.
8. The figure is displayed with the configured stroke and fill attributes.
